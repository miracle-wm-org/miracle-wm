**miracle-wm** is the hackable, stylish, and modern Wayland compositor based on
[Mir](https://github.com/MirServer/mir). It is a manual tiling window manager at its core, 
but it can do so much more than that with the help of its rich plugin system. 

![miracle in action](./resources/screenshot1.png "miracle in action")

For installation instructions, build instructions,
and a roadmap, visit: https://wiki.miracle-wm.org/latest/
